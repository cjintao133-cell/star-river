# Star River（星河）· 产品说明

## 一句话定位

**设备侧的「赛博生命」内核**：记忆、情绪、主动这些决定"它是谁"的东西，长在你自己的设备上；只有"动脑推理"这一步，由你选择的模型端点完成——可以是云，也可以是你本机跑的离线模型。

> 精确说法：**本地内核 + 自带端点（BYOK）推理**。不是"所有数据永不出设备"，也不是"又一个云端 AI 壳"。

## 它是什么

一个用 **Go + C** 写的内核（kernel），把"一个能长期陪伴的 AI"所需的地基做扎实，好让你在其上搭 App、或作为框架复用：

- **事件总线**（`bus`）：模块间发布/订阅互不耦合，状态变更走门铃广播。
- **多协议模型接入**（`adapter/openai`、`adapter/anthropic`、`adapter/gemini`）：任意端点、任意厂商，统一适配；含模型探测、能力发现、embedding。
- **存储**（`store`）：SQLite（纯 Go、零 cgo）+ 字段级 AES-GCM 加密 + 版本化迁移。
- **上下文编排**（`orchestrator`）：七层上下文装配 + 字符/token 预算分配 + 摘要接力。
- **工具与 MCP**（`tool`、`tooldisc`）：MCP 客户端/管理器（远程 HTTP + stdio）+ 内置工具 + 工具发现。
- **角色卡**（`cards`）：V1/V2/V3 JSON、chara PNG、charx（zip）、世界书（触发词激活/递归/常驻）。
- **记忆**（`hippocampus`）：艾宾浩斯遗忘曲线、强化、按留存度召回。
- **情绪**（`endocrine`）：五维情绪状态机（数据驱动可扩维），双路径推演（对话触发 + 定时衰减）。
- **主动**（`proactive`）：三类触发源（记忆到期/日程/情绪阈值）+ 三重闸门（去重/限频/静默时段）。
- **视觉**（`visual`）：多方言图像生成/编辑 + 强制 AI 水印 + 能力探测降级。
- **语音/搜索/密钥/备份/诊断/多语言**（`voice`/`search`/`secret`/`backup`/`diag`/`i18n`）。
- **C 热点**：设备探测、int8/NEON 向量检索（`native/`）。
- **桥接**：`mobilebind`（gomobile → Android AAR）、`desktopbind`（c-shared DLL + JNI → 桌面）。

## 它不是什么

- 不是开箱即用的成品 App。**UI 是参考实现，已暂时移出主树（WIP）**，本仓库聚焦内核/框架。
- 不是"跑个模型就完事"的聊天壳——它的价值在**记忆/情绪/主动构成的持续性**，而不是单轮问答。
- 不是"数据永远不出设备"——见下面的诚实边界。

## 诚实的数据边界（务必先读）

| 数据 | 在哪 | 出设备吗 |
|---|---|---|
| 会话/消息、长期记忆、向量索引 | 本地设备（SQLite，正文 AES-GCM 加密） | 不出 |
| 情绪状态、主动调度状态 | 本地 | 不出 |
| API 密钥（BYOK） | 系统密钥库（Android Keystore / Windows DPAPI） | 不出 |
| 崩溃 dump | 本地文件，**无网络上传能力** | 不出 |
| **对话上下文（prompt）** | 发送到 **你自己填的模型端点** | **会**（发给该端点） |
| **生图 prompt** | 同上，发给你填的图像端点 | **会** |

**一句话**：本项目**没有自有后端**、**无遥测/埋点回传**；数据只会去**你自己配置的那个端点**。端点填云端=发云端，端点填本机 Ollama=全程离线。

## 适用 / 不适用

- ✅ 想在自己设备上养一个**有持续记忆和情绪**的 AI 伴侣，且要掌控数据与密钥。
- ✅ 想在本地/内网跑、甚至完全不联网（接本地模型）。
- ✅ 想拿一个干净的 Go 内核当底座，自己搭 UI / App / 服务。
- ❌ 想要一个装上就能聊的成品 App（当前没有成品 UI）。
- ❌ 追求"生产级已审计安全"（见 KNOWN-ISSUES，8 处待外部安全评审）。

## 与同类的关系（诚实坐标）

- 同物种最接近者：AIRI（"container of cyber livings"，Web/桌面容器）。
- 本项目的差异坐标：**设备侧、纯 Go 内核、C 热点、双端同记忆、零自有后端**；而非"又一个 web 容器"或"云端 SaaS"。

> 注：本项目不追逐"star 数"竞赛；目标是在"设备侧本地生命内核"这个坐标上做一个**可信、可复用**的地基。
